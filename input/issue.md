Set up the Expo project foundation:
- Initialize with `create-expo-app` using blank TypeScript template
- Create `app.config.ts` with: app name/slug, iOS bundleIdentifier, deployment target 16.0, HealthKit entitlement (`com.apple.developer.healthkit`), Info.plist `NSHealthShareUsageDescription` and `NSHealthUpdateUsageDescription`, `expo-dev-client` plugin
- Configure `tsconfig.json` with strict mode extending `expo/tsconfig.base`
- Install all production dependencies: `expo-router`, `expo-linking`, `expo-constants`, `expo-status-bar`, `expo-dev-client`, `react-native-health`, `zustand`, `date-fns`, `react-native-gifted-charts`, `expo-sqlite`, `react-native-safe-area-context`, `react-native-screens`, `@expo/vector-icons`
- Install dev dependencies: `jest-expo`, `@testing-library/react-native`, `@testing-library/jest-native`, `@types/react`, `eslint`, `@typescript-eslint/eslint-plugin`, `@typescript-eslint/parser`, `eslint-config-expo`, `typescript`
- Create project structure directories with `.gitkeep`: `components/`, `services/`, `stores/`, `hooks/`, `types/`, `constants/`, `utils/`
- Verify `npx expo prebuild` succeeds and generates an iOS project
