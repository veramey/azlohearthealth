## Visual identity

Dark, premium aesthetic inspired by WHOOP and Oura (2025 redesigns).

## Colors

- Background primary: #0D0D0D
- Background surface/cards: #1A1A1A
- Norm green (normal): #22C55E
- Norm yellow (borderline): #EAB308
- Norm red (outside normal): #EF4444
- Text primary: #E5E5E5
- Text muted: #888888

## Typography

- Font: SF Pro (system)
- Generous spacing, content breathes

## Components

- Cards: Rounded corners (12-16px), subtle border or elevated surface
- Charts: Line charts with gradient fill below the line
- Icons: SF Symbols
- Minimum tap target: 44x44pt (Apple HIG)

## Principles

- Data-first: the most important number is the most prominent element
- Glanceable in <3 seconds
- No decorative elements — every pixel serves a purpose
- Dark mode only — no light mode in MVP
